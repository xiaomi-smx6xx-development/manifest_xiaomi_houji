# xiaomi-houji manifest
Manifest for Xiaomi 14 custom ROMs.

#  How to use this file?

Clone this repo in rom source.

For LineageOS 24.0 unofficial based rom's
    
    git clone https://github.com/xiaomi-smx6xx-development/manifest_xiaomi_houji.git .repo/local_manifests  -b lineage-24.0

You can modify the dependencies and packages according to your wish.
